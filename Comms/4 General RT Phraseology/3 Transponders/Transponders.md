Transmits a coded response wheneber it is interrogated by a secondary surveillance radar (SSR). The coded information is displayed on the ATC controller's screen![[Pasted image 20261029161441.png]]

Dependent on make and model,modern transponders transmit:
* Mode A: 4 digit code utually at the request of ATC (a squak)
* Mode C: A pressure altitude, referenced to 1013.25hPa
* Mode S: a wide variety of information,including:
	* The aircraft's ICAO 24-bit code
	* The aircraft's callsign or flight ID
	* Other information about the aircraft's flight path

IDENT FUNCTION
The IDENT button causes the aircraft symbol on the controller's screen to be temporaly highlighted. If a radar controler asks you to 'squawk ident', press button IDENT.
