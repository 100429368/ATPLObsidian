Since the most meteorological observing stations are not located precisely at the aerodrome  reference point a small corection may have to be applied to adjust for any difference in elevation between the observing station and the reference point.

QFE is measured by a suitably qualified Air Traffic Services ( ATS ) person. Usually this is done using an altimeter located in the local (visual) control room. The actual reading is adjusted  for the elevation difference between the altimeter and the aerodrome reference point.

An altimeter whose zero datum is set to QFE ,will read zero feet at the aerodrome reference point.
